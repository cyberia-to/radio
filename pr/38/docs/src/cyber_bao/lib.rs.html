1//! Poseidon2-BAO: verified streaming with Poseidon2 hash over Goldilocks.
2//!
3//! This crate provides BAO-style content-verified streaming using the
4//! Poseidon2 algebraic hash function. The tree structure
5//! and encoding formats are compatible with the original bao specification,
6//! differing only in the hash function used.
7//!
8//! # Architecture
9//!
10//! - **`tree`**: Pure geometry — tree node indexing, chunk counting, block sizes
11//! - **`hash`**: Pluggable hash backend trait with Poseidon2 implementation
12//! - **`io`**: Encoding, decoding, outboard creation, and slice extraction
13
14#![cfg_attr(not(feature = "std"), no_std)]
15

17pub mod hash;
18#[cfg(feature = "std")]
19pub mod io;
20pub mod tree;
