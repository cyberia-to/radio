Expand description

Strict complete-buffer proofs for the canonical fixed-4096 Hemera tree.

Concrete Poseidon2 kernels, counters and domains are those of Hemera d5f0a095. A proof is an LE u64 complete length, then selected preorder child pairs and whole group payloads. Every hash is four canonical LE field words. Grouping changes the carrier, not the complete ROOT; historical internal CVs are not roots. Legacy std carrier APIs have their own, unchanged admission behavior.

VerifiedProof
Complete proof validation relative to the supplied root and complete size. This sealed view does not establish a particle/root association. It retains only immutable proof bytes and the admitted root/size/block/request tuple; successful validation establishes the fixed eight-byte header for replay. It can outlive its verifier, but cannot outlive or mutate the proof storage.
