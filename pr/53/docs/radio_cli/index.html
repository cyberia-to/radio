radio-cli’s own logic, importable outside the radio binary.

Everything here is free of clap, tokio and the iroh endpoint: pure parsing and encoding, the CLI’s own domain rules independent of the terminal it happens to run in. This is the seam a future integration test (row 22, particle-addressed blob fetch) builds on — an integration test lives in a separate crate under tests/, and a separate crate can only see a [lib] target, not main.rs.
