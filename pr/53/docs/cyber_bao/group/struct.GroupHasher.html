Expand description

A resumable complete-left binary reduction over fixed 4096-byte chunks.

Construction and completed polls call no backend method. Every pending step performs exactly one leaf or parent kernel: for N chunks (at least one, even for empty input), completion takes exactly 2*N-1 steps. Only the completing kernel receives the requested root flag.

The caller owns scheduling: check is_complete, admit one unit from its persistent budget, then step. Intermediate steps return None while is_complete is false; count kernel entries, not returned hashes. No internal quota is renewed by polling. Backend panics have no recovery contract. Hashes are moved, never cloned.

The frontier uses 53 slots: a u64 byte length needs at most 2^52 leaves; before a leaf there are at most 52 complete peaks, plus the incoming leaf. This fixed storage does not require allocation or a placeholder hash.

Borrow a group and validate every counter before any hashing.

Empty input is a single empty leaf. A sole leaf at u64::MAX is valid; two leaves starting there return GroupHashError::CounterOverflow.

pub fn step(&mut self) -> Option<B::Hash>

Perform one pending kernel and return the hash only on the final step.

Intermediate steps return None with is_complete() == false. Completed polls return None with is_complete() == true and perform no kernel.
