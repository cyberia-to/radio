Incremental fixed-chunk group hashing with a fixed frontier.

This computes a hash only; it does not authenticate data or a particle/root association. Each pending step calls one backend kernel, on at most 4096 input bytes or two child hashes. Arbitrary backend code and hash destructors retain their own cost and allocation behavior.
